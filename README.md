# Sales-Performance-Profitability-Analysis-Dashboard

About the Project
This project is a Sales Performance and Profitability Dashboard
created using Microsoft Power BI.

The dashboard helps users understand sales and profit performance
through different charts and visuals. It shows how sales are performing
across customer segments, product categories, sub-categories, states,
months, and shipping modes.

The main purpose of this project is to make sales data easier to
understand and help users identify useful business insights.

Tools Used
- Microsoft Power BI -- To create the dashboard and visual
  reports.
- Power BI Visuals -- To present the data using charts, graphs,
  and a map.
- SuperStore Sales Dataset -- The dataset used for the analysis.

Dashboard Features
The dashboard contains the following visualizations:
1. Sales by Segment -- Shows the sales contribution from Consumer,
   Corporate, and Home Office segments.
2. Monthly Sales by Year -- Compares monthly sales for 2019 and
   2020.
3. Monthly Profit by Year -- Shows the monthly profit trend and
   compares both years.
4. Sales by State -- Displays sales and profit across different
   states on a map.
5. Sales by Sub-Category -- Highlights sub-categories such as
   Phones, Chairs, and Binders.
6. Sales by Category -- Compares sales across Office Supplies,
   Technology, and Furniture.
7. Sales by Ship Mode -- Shows sales based on Standard Class,
   Second Class, First Class, and Same Day shipping.

Dataset Information
The project uses the SuperStore_Sales_Dataset table.

Some of the main columns used in the dataset are:
- Order ID
- Order Date
- Ship Date
- Ship Mode
- Customer Name
- Segment
- State
- Region
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Profit
- Payment Mode

Key Insights
From the dashboard, users can:
- Compare sales from different customer segments.
- Understand monthly sales and profit trends for 2019 and 2020.
- See which product categories and sub-categories have higher sales.
- Explore sales and profit across states.
- Compare the sales contribution of different shipping methods.

How to Open the Project
1. Download or clone this repository.
2. Open the .pbit file using Microsoft Power BI Desktop.
3. If Power BI asks for a data source, select the required SuperStore
   sales dataset and follow the prompts.
4. Load or refresh the data if required.
5. Explore the dashboard in Power BI Desktop.
